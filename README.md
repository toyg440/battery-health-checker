# Battery Health Checker

A simple Windows or Linux application that checks your laptop's battery health by analyzing the battery report generated by the kernel.

## Features
✅ Generates a new battery report automatically.<br>
✅ Reads the latest battery report from the default `C:\Users\[Username]` (windows) or `/org/freedesktop/UPower/devices/battery_BAT0` (linux) folder.<br>
✅ Displays battery health percentage based on design and full charge capacity.<br>
✅ Shows when the report was last generated.<br>
✅ User-friendly interface with buttons to update and check battery health.<br>

## Prerequisites
For Windows:
- Windows OS
- Python (If you wish to use the python version)

For Linux:
- Any linux distro that has the Linux kernel power subsystem
- UPower
- Python 3.8+
- Python3-tk (important)


## Usage
Windows:
1. Download the latest `.exe` or the `.py` file from the [Releases](https://github.com/toyg440/battery-health-checker/releases) page.
2. Double-click the `.exe` or the `.py` file to launch the application.

Linux:
1. Download the `.py` file from the [Releases](https://github.com/toyg440/battery-health-checker/releases) page.
2. Right-click the downloaded file and click 'Run as program'.
